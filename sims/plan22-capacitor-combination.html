วงจรตัวเก็บประจุ (จำนวนเครื่องหมาย + และ − บนแผ่นแสดงขนาดของประจุ)

ตัวเก็บประจุC (μF)Q (μC)V (V)U (J)

ทำไมต่ออนุกรมแล้วประจุเท่ากันทุกตัว

ก่อนต่อแบตเตอรี่ ทุกแผ่นไม่มีประจุ · แผ่นขวาของ C₁ กับแผ่นซ้ายของ C₂ ต่อถึงกันด้วยลวด แต่ไม่ได้ต่อกับแบตเตอรี่โดยตรง (เป็นส่วนที่แยกโดดเดี่ยว) ประจุรวมของส่วนนี้จึงเป็นศูนย์ตลอด · เมื่อแบตเตอรี่ดึงอิเล็กตรอนออกจากแผ่นซ้ายของ C₁ (แผ่นนี้มีประจุ +Q) ไปไว้ที่แผ่นขวาของ C₂ (แผ่นนี้มีประจุ −Q) แผ่นด้านในถูกเหนี่ยวนำ แผ่นขวาของ C₁ มี −Q แผ่นซ้ายของ C₂ จึงต้องมี +Q เพื่อให้รวมกันเป็นศูนย์ · ดังนั้นตัวเก็บประจุทุกตัวที่ต่ออนุกรมมีประจุ Q เท่ากัน

ควบคุม

C₁ (μF)C₂ (μF)C₃ (μF)แบตเตอรี่ V (V)

C ใส่ได้ 0.5 ถึง 50 μF · V ใส่ได้ 1 ถึง 100 V · ตัวเก็บประจุเริ่มต้นไม่มีประจุ

-Q รวมที่แบตเตอรี่ให้ (μC)

ลองทำ

  1. กด "ซ่อนคำตอบ" แล้วกดตัวอย่างขนาน ทำนาย Ceq Q รวม และ Q ของแต่ละตัว ก่อนเปิดดู
  2. สลับเป็นอนุกรม ตัวใดได้ V มากที่สุด เพราะอะไร
  3. กดใบงานข้อ 3.1 ถึง 3.5 ตรวจคำตอบในใบงาน
  4. Ceq แบบขนานมากกว่าตัวที่ใหญ่ที่สุดเสมอ แบบอนุกรมน้อยกว่าตัวที่เล็กที่สุดเสมอ จริงหรือไม่

      สูตรที่ใช้

      1. ขนาน: V เท่ากัน · Q = Q₁ + Q₂ + … · Ceq = C₁ + C₂ + …
      2. อนุกรม: Q เท่ากัน · V = V₁ + V₂ + … · 1/Ceq = 1/C₁ + 1/C₂ + …
      3. Q = CV · U = ½CV² = Q²/(2C) = ½QV
      4. วงจรผสม: ยุบกลุ่มในสุดก่อน หา Q รวม แล้วย้อนกลับ
      5. ทนแรงดัน: อนุกรม Q เท่ากัน ตัวที่ C น้อยรับ V มาก ใช้ Q ที่น้อยที่สุดที่แต่ละตัวทนได้

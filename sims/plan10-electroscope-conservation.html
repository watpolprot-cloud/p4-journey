อิเล็กโทรสโคปแบบใบโลหะ

ทำนายก่อนทุกครั้ง แล้วจึงเลื่อนแท่งหรือกดปุ่ม · วงกลมเล็กแทนประจุส่วนเกินบางส่วน

ควบคุม

0ประจุรวมของอิเล็กโทรสโคป
หุบใบโลหะ
ยังไม่มีขั้นตอน

ลองทำ (ตรงกับใบงานตอนที่ 2 และ 5)

  1. เป็นกลาง: เลื่อนท่อ PVC เข้าใกล้ แล้วถอยออก ใบเป็นอย่างไร
  2. เลื่อนจนชิด กด “แตะแท่ง” แล้วถอยแท่งออก ใบยังกางหรือไม่ มีประจุชนิดใด
  3. เหนี่ยวนำ: แท่งใกล้ → แตะด้วยนิ้ว → เอานิ้วออก → ถอยแท่ง ได้ประจุชนิดใด
  4. เริ่มจาก “มีประจุลบ” หรือ “มีประจุบวก” แล้วนำท่อลบเข้าใกล้ช้า ๆ ใบเป็นอย่างไร

ทรงกลมโลหะขนาดเท่ากัน 3 ลูก บนฐานฉนวน

ตั้งประจุเริ่มต้น กด “ตั้งค่า” แล้วเลือกคู่ที่จะแตะกัน · ประจุรวมคงตัวเสมอ
ขั้นการแตะA (nC)B (nC)C (nC)รวมอิเล็กตรอนที่ย้าย

ควบคุม

A (nC)B (nC)C (nC)
q′ = (q₁ + q₂)/2

ลองทำ

  1. A = +12 B = −4 แตะกัน ตรวจใบงานข้อ 4.5 อิเล็กตรอนย้ายจากลูกใดไปลูกใด
  2. A = +8 B = C = 0: A แตะ B แล้ว A แตะ C (ข้อ 4.3)
  3. เปิด “ซ่อนผล” ให้เพื่อนทำนายก่อน แล้วจึงเปิดดู

วางประจุลบที่ปลายซ้ายของแท่งโลหะและแท่งพลาสติก
